# Souris Design Reference Export

This directory contains the original exported design prototype.

It is reference material only.

It may contain:
- HTML
- CSS
- JavaScript
- screenshots/previews
- design context
- design assets

Do NOT import this code into the React Native application.

Do NOT port its DOM structure or CSS architecture.

Use it to understand:
- visual hierarchy
- spacing
- colors
- typography
- screen composition
- interaction intent
- appointment layout
- processing-time representation

For implementation decisions, read first:

1. `/CLAUDE.md`
2. `/AGENTS.md`
3. `/docs/design/DESIGN_OVERRIDES.md`
4. `/docs/design/DESIGN.md`
5. `/docs/design/DESIGN-HANDOFF.md`

Runtime application assets belong under `/assets`, not in this reference directory.
