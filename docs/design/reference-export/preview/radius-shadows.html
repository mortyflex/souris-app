Rayons & ombres

Trois rayons, trois ombres. Les ombres sont teintées navy et volontairement au bord du visible : rien ne flotte sans raison, et aucune ombre n’est noire.

Source : --r, --r-lg, --r-pill, --shadow-* de assets/souris.css → tokens.css

Rayons

Défaut
--r · 8 px
Bouton, champ, puce, événement, pastille d’icône.
Feuille iOS
--r-lg · 16 px
Uniquement en haut : la feuille est ancrée au bas de l’écran.
Pilule
--r-pill · 999 px
Avatar, FAB iOS, point de puce, poignée, indicateur.

Sur Android, --r passe à 12 px, --r-lg à 28 px, le FAB à 16 px et les boutons deviennent des pilules — par convention Material, pas par goût.

Ombres

Élévation légère
--shadow-raise
0 1px 2px oklch(.25 .06 285 / .10), 0 6px 16px −10px oklch(.25 .06 285 / .28)

Onglet segmenté sélectionné, toast, seconde cliente placée pendant une pose.

Feuille modale
--shadow-sheet
0 −1px 0 var(--border), 0 −12px 32px −18px oklch(.25 .06 285 / .35)

Ombre dirigée vers le haut : la feuille monte depuis le bas de l’écran.

FAB
--shadow-fab
0 4px 14px −4px oklch(.46 .14 300 / .5)

Teintée lavande, pas grise : l’ombre appartient au bouton qui la porte.
